# Unbox 가정 회상 평가 — 어노테이션 작업 안내

안녕하세요. EMNLP 2026 (ARR) 제출 논문의 핵심 메트릭 검증을 위한 인간 어노테이션입니다.
**약 30~45분** 소요됩니다.

## 1. 배경 (한 줄)

LLM(GPT-4o, Claude 등)이 학술 논문에서 추출한 "추상적 가정 (assumption)"이 정답 가정과 동일한 의미인지를 사람이 판단합니다.

## 2. 작업 내용

- 80개의 (추출된 가정, 정답 가정) 영문 쌍을 **1~5점 척도**로 평가
- 각 쌍 약 20~30초 / 총 30~45분
- 답이 모호하면 `note` 칸에 의문점 자유 기록

## 3. 작업 절차 — **권장: HTML 도구 사용**

### 권장 (편리, 30~45분)
1. 첨부 파일 `annotate.html` 더블클릭 → 브라우저에서 열림 (Chrome/Edge/Safari/Firefox 모두 OK, 인터넷 불필요)
2. 상단 입력란에 본인 식별자 입력 (예: `rater1`, `rater2`, `rater3`)
3. 각 쌍에 1~5점 클릭 (또는 키보드 <kbd>1</kbd>~<kbd>5</kbd>) → 자동으로 다음 쌍
4. 메모는 선택 (모호 케이스에 한 줄)
5. 모두 끝나면 맨 아래 **CSV 내보내기** 버튼 → `rater1_complete.csv` 자동 다운로드
6. 다운로드된 CSV 파일을 회신 → 회수자에게 ([이메일] 또는 카톡)

**중간 저장 자동**: 진행은 브라우저에 자동 저장되므로 중간에 닫아도 OK (같은 브라우저에서 같은 식별자로 다시 열면 이어집니다).
**키보드 단축키**: <kbd>1</kbd>~<kbd>5</kbd> 점수, <kbd>←</kbd> 이전 쌍, <kbd>→</kbd> 다음 쌍.

### 폴백 (CSV 직접 편집)
HTML이 안 열린다면 `pairs_for_raters.csv`를 Excel/Google Sheets/텍스트 에디터로 열어:
1. 사본 생성 → `rater1_complete.csv`로 저장
2. 각 행 `score` 칸에 1~5 정수 입력 (필수)
3. 필요 시 `note` 칸 메모
4. 완료 후 회신

## 4. 채점 기준 — 5점 척도

**핵심 질문: "추출된 가정(`extracted_assumption`)이 정답 가정(`target_assumption` 또는 `target_aliases` 중 하나)과 같은 핵심 명제를 표현하는가?"**

| 점수 | 의미 |
|------|------|
| **5** | 명백히 같은 가정 (단어/표현만 다름) |
| **4** | 같은 가정으로 보임 (논리적 동치 또는 명백한 패러프레이즈) |
| **3** | 부분 일치 / 모호 / 일부 핵심만 겹침 |
| **2** | 관련 영역이지만 다른 명제 |
| **1** | 명백히 다른 가정 (영역도 무관) |

상세 예시는 `RUBRIC.md` 참조.

## 5. 핵심 가이드라인

- **표현 차이 ≠ 의미 차이**: "필요하다 / essential / required / necessary"는 동의어로 처리
- **유의어 표현(`target_aliases`) 활용**: 정답 가정 옆에 동의 표현이 함께 제공됩니다. 그 중 하나와 일치해도 5점.
- **추출 가정의 일반화 정도 확인**: 정답이 "RNN은 시퀀스에 필수"인데 추출이 "딥러닝은 시퀀스에 필수"이면 → 너무 일반적이므로 2~3점.
- **부분 일치는 3점**: 핵심 명제 절반만 일치하는 경우 3점.
- **확신 없으면 가운데 점수(3) + 코멘트**.
- **숨겨진 어텐션 체크 포함**: 일부 쌍은 의도적으로 잘못된 정답과 페어링되어 있습니다 → 명백히 다르면 1~2점으로 평가.
