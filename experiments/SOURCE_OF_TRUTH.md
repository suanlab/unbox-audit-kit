## Reproducibility notes

- **Consistency check, not recomputation.** `scripts/reproduce_paper_tables.py`
  re-reads the frozen artifacts and asserts every headline number (60/60); it
  does **not** recompute them. `scripts/canonical_evaluator.py` requires the
  OpenAI `text-embedding-3-small` API and is **single-run**.
- **Wrong-corpus** (`experiments/wrong_corpus_control/summary.json`): GPT-4o,
  `temperature=0`, `seed=42` (set in `scripts/run_wrong_corpus_control.py:104`),
  single run; the summary does not self-record the seed.
- **Cross-LLM sweep** (`experiments/{llama3_1_8b,qwen2_5_7b,mistral_7b}_clean/`):
  single run, `seed=42`, `temperature=0`, 1×A100-80GB,
  `gpu_memory_utilization=0.50`. Exact stack pinned in **`requirements-oss.txt`**
  (vllm==0.7.3, torch==2.5.1, transformers==4.49.0; not in the core
  `requirements.txt`). Canonical numbers use the OpenAI embedding API, not
  `sentence-transformers` (the latter is only for the explicitly
  non-canonical prelim, `experiments/oss_llm_prelim_eval.md`).
- **Human α** is computed by the canonical coincidence-matrix Krippendorff
  estimator, cross-validated against an independent implementation (and the
  `krippendorff` PyPI lib when installed) in `tests/test_krippendorff.py`.
  Raw rater CSVs are withheld for annotator privacy; only the anonymized
  aggregate `annotation/g1_results.json` is released, so α is verified by the
  unit test rather than recomputed from raw data.

## Scope of the Protocol Freeze

Only the **initial 4-primary-shift** protocol (Transformer, Diffusion, ICL, ViT; target-assumption aliases; soft-matching threshold 0.65) is covered by the SHA-256-hashed freeze in `.sisyphus/evidence/protocol_freeze.json`.

All of the following were developed **post-hoc** and reported transparently as stress tests:

- 6-case extension (ResNet, GAN, Word2Vec, Dropout, BatchNorm, BERT)
- Retrieval baselines (TF-IDF, BM25)
- Contamination analysis (popularity ρ)
- Error analysis
- Confidence calibration
- Synthetic literature control
- Niche subfield control
- Cross-model comparison (GPT-4o vs Claude)

No metrics or target-assumption aliases were changed after the initial 4-case experiments started.

## Target-Assumption Construction

Targets and 2–3 aliases per breakthrough are stored in `data/paradigm_shift_mapping.json` and authored by the paper's authors from canonical descriptions in survey papers and original breakthrough papers. **These are author-defined targets, not independently annotated ground truth.** An independent human-expert annotation study is listed as future work and is the single most impactful follow-up experiment.

- `experiments/gpt4o_clean_prompt/summary_STALE_similarity_reranked.json` — earlier run that re-sorted by cosine similarity instead of confidence order; retained only for audit trail. **Do not use for any paper claim.**
- `experiments/failed_runs/` — runs that terminated due to API quota exhaustion or other errors; not used for any paper claim.

## Metric Validation: What "Cohen's κ = 0.97" Actually Refers To

The 80-pair *program-vs-program* simulation (`scripts/run_rulebased_match_simulation.py` → `.sisyphus/evidence/human_annotation_results.json`) is a **rule-based structured-matching simulation using two deterministic keyword-pattern labelers** (a "strict" and a "moderate" variant). The κ = 0.97 is agreement **between these two automated programs**, not between human raters. This is **superseded** by the real human study in `annotation/g1_results.json` (10 raters, α=0.634, human–rule κ=0.702); the simulation is retained only as a deterministic regression check.
